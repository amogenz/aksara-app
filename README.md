# Aksara — Unduh Resmi

Kanal rilis resmi aplikasi **Aksara** oleh AMOGENZ.

Repo ini khusus untuk mengunduh APK. Kode sumber aplikasi tidak ada di sini.

## Cara unduh

1. Buka tab **Releases**.
2. Pilih versi bertanda **Latest** (paling baru dan stabil).
3. Di bagian **Assets**, unduh berkas berakhiran `.apk`.
4. Buka berkas itu di HP Android untuk memasang / memperbarui.

Versi bertanda **Pre-release** adalah versi Beta untuk penguji — isinya belum
final. Pembaruan di dalam aplikasi juga mengambil berkas dari repo ini.

## Tentang Aksara

Aksara adalah aplikasi komunitas AMOGENZ: umpan komunitas, chat, dan story
dalam satu tempat.
